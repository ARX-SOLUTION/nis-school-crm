Core Design Principles 5 Immutable Tenets
01 / DENSITY

Density with Clarity

Enterprise school operators process high volumes of student transactions, contract states, and attendance logs. Every pixel must earn its presence: eliminate decorative clutter, heighten typography contrast, and use tabular numerals for alignment.

02 / ANATOMY

Predictable Anatomies

Every card, table, modal, and drawer follows a shared layout rhythm across all 14 CRM modules. Operators never need to re-learn where primary actions live, where filters reside, or how table pagination behaves.

03 / DEPTH

Deliberate Dark Hierarchy

Pure pitch-black (#000000) is banned for UI surfaces to avoid severe contrast fatigue. We step from Canvas (#090D16) to Cards (#0F172A) to Elevated Sub-surfaces (#1E293B) with precision 1px borders.

04 / STATE

Instant State Feedback

Every clickable element provides explicit feedback within 150ms. Hover, active press, keyboard focus (2px blue ring with 2px offset), and disabled states adhere strictly to WCAG 2.1 AA specifications.

05 / SAFETY

Type-Safe Design Tokens

All styling values map strictly from tailwind.config.ts into strongly-typed React component props. Arbitrary magic values (e.g. bg-[#131d2f] or p-[13px]) are rejected at lint time.

Implementation Discipline Do vs Don't
DO: Layer Depth & Compound Components

Compose views using the standardized <Card> component hierarchy, 1px slate-800 borders, and tabular numbers for all money amounts and dates.

<Card>
  <CardHeader><CardTitle>To'lovlar</CardTitle></CardHeader>
  <CardContent><span className="tnum">1 250 000 so'm</span></CardContent>
</Card>
DON'T: Raw Magic Divs & Pure Blacks

Never use raw div with inline hex codes, pitch black (#000000) backgrounds, or skip surface elevation levels without container borders.

<div className="bg-[#000] p-3 rounded-[13px]">
  <h2>To'lovlar</h2>
  <p>1250000 sum</p>
</div>

Writing & Localization Rules Uzbek Latin Specification
W1 · CASE

Sentence Case Baseline

Headings and action buttons always use sentence case (e.g., "Yangi talaba qo'shish"). ALL CAPS is strictly reserved for micro status pills (11px, +8% tracking).

W2 · ORTHOGRAPHY

Typographic Apostrophes

Uzbek Latin characters o' and g' use the typographic apostrophe U+2019 (’), never raw tick (`) or ASCII quotation mark (').

W3 · CURRENCY & DATES

Tabular Finance Formats

Money sums always use thin group spaces: 1 250 000 so'm. Dates follow ISO 8601 YYYY-MM-DD format with explicit tabular digit spacing.

W4 · ACTIONS & ERRORS

Direct Verbs & Recovery Path

Buttons specify the precise action ("Saqlash", "Eksport qilish"). Error alerts describe the problem and the immediate recovery route.

Interaction & State Contracts 8 Strict Rules
B1 · SINGULAR ACTION

One Primary Action per View

Each viewport region features exactly one solid Tech Blue button. Secondary controls are outline or ghost; destructive actions are red-tinted and isolated.

B2 · TOUCH AREA

≥ 44px Interactive Tap Targets

In accordance with Fitts's Law, touch targets ship with minimum min-h-[44px] bounds. Desktop buttons are ≥36px with full keyboard accessibility.

B3 · ASYNC LOCK

Submission Spinners & Form Lock

Buttons performing network actions show an inline spinner, lock their width to prevent layout shifts, and temporarily disable the form.

B4 · DIALOG MODAL

Native <dialog> & Focus Trap

Modals render with showModal(), a dark backdrop with blur, and trap tab navigation. Pressing Esc smoothly closes the overlay.
